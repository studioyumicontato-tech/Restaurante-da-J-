# Restaurante da Jô

Site institucional responsivo do Restaurante da Jô, em Arujá (SP), com foco em apresentar o restaurante e facilitar pedidos pelo WhatsApp.

## Como visualizar

Abra `index.html` em um navegador. O site usa CSS e JavaScript sem dependências de build.

## Personalização

- **Cardápio:** edite os cards em `index.html`. Os valores estão como “Consulte disponibilidade” para não divulgar preços ou disponibilidade não confirmados.
- **Fotos:** as imagens atuais são ilustrativas e carregadas do Unsplash. Troque-as por fotos próprias autorizadas antes de divulgar como imagens do restaurante.
- **Horário:** configure o horário na seção de contato depois de confirmar os dados; no momento o site orienta o visitante a consultar pelo WhatsApp.
- **Avaliações:** o espaço não contém depoimentos fictícios; pode receber avaliações reais e autorizadas futuramente.
- **Métricas:** Google Analytics e Meta Pixel podem ser adicionados quando os respectivos IDs forem fornecidos.

## Acessibilidade e recursos

Navegação adaptada a dispositivos móveis, links com contexto acessível, filtros por categoria, lightbox nativo, animações com suporte a `prefers-reduced-motion`, lazy loading para imagens abaixo da dobra e dados estruturados de restaurante.
